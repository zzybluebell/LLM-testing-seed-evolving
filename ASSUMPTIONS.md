# ASSUMPTIONS.md

Each entry: assumption → reason. Dates are absolute.

2. **GLM-5.2 (`glm-5-2-260617`, Ark) replaces Kimi K3 as the third domestic competitor** (user instruction 2026-09-10). 3. **Ark route is `/api/compatible`** (pay-as-you-go Anthropic-compatible), not `/api/coding` or `/api/plan`, which require Coding/Agent Plan subscriptions.
4. **Every request of a run hits the model under test.** `ANTHROPIC_DEFAULT_{HAIKU,SONNET,OPUS}_MODEL` and `CLAUDE_CODE_SUBAGENT_MODEL` are set to the model for all models including Opus, so background "haiku" helpers and subagents cannot silently use a different model. This is what Ark's Claude Code guide recommends; applied to Opus too for symmetry.
5. **`CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC=1`** for all models so telemetry does not appear as extra requests or quota use.
6. **Each run gets a fresh `CLAUDE_CONFIG_DIR`** (inside the run directory) so the user's global `~/.claude/settings.json`, `~/.claude.json`, plugins, MCP servers and hooks cannot influence any model. Verified to work 2026-09-10.
7. **Effort = high for all models via `--effort high`** (flag exists in claude 2.1.231; Ark recommends effort high for Evolving). Whether third-party endpoints honour it is an open VERIFY item.
8. **Thinking stays at Claude Code's default (enabled)**; no `CLAUDE_CODE_EXTRA_BODY` override.
9. **Opus authenticates with `CLAUDE_CODE_OAUTH_TOKEN` from `.env`** (generated by the user with `claude setup-token`), allow-listed only for the opus model. Reason: the Keychain credential of the standalone CLI is expired and a long-lived token is the only path that stays re-runnable weeks later under a clean environment.
10. **Opus model ID is `claude-opus-5`** (current Opus per the Claude API reference); TASK.md's `claude-opus-4-7` is superseded.
11. **`models.yaml` nests models under `models:` and adds `common_env:`** (small deviation from TASK.md's flat layout) to avoid repeating two lines five times; `run_one.py` merges `common_env` then the model's `env`.
12. **Cost rule:** `cache_creation` tokens billed at the input price; Ark's per-hour cache-storage fee ignored; CNY→USD at `FX_CNY_PER_USD=7.15`.
13. **Python 3.13.7 for the venv** (3.11 is also installed; TASK requires ≥ 3.11).
14. **`claude` subprocesses get `stdin=/dev/null`** to avoid the "no stdin data received in 3s" wait seen in the smoke test.
15. **`--include-partial-messages` is added to the Claude Code flags** so the raw `message_delta` usage is logged; without it per-turn output tokens are unobservable (always 1). It changes only what the CLI prints, not model behaviour; the log grows by the content deltas.
16. **Per-turn token counts come from `stream_event` message_start/message_delta**; `assistant` events supply content only. Session totals are also cross-checked against the final `result` event.
17. **A "turn" is one assistant message (unique message id), subagent messages included** (`subagent_turns` is reported separately).
18. **check.py heuristics (documented for auditability):** sheet names match case-insensitively after stripping spaces/underscores/hyphens; a metric cell is the first numeric/formula cell to the right of (else below) a matching label, with NPV/IRR/PMT also found by formula text; among several candidates the one nearest the truth is scored; the assumption-input block excluded from `formula_ratio` is every row from a cell containing "assumption"/"input" down to the next empty row (max 15 rows); "payment rows" in the loan sheet are rows with ≥ 3 numeric/formula cells; placeholder patterns are `lorem`, `\bTBD\b`, `\bXXX\b`, `[insert`; numbers accept thousands separators, currency symbols, k/M suffixes, percent (matched as both 12.3 and 0.123) and parentheses negatives.
19. **NPV/IRR evaluation path:** cached values if the file has them, LibreOffice `soffice` if installed, else the `formulas` package (pinned in requirements.txt). The path used is recorded in `check.json.eval_path`.
20. **Chart colours** are slots 1–4 of the dataviz reference palette in fixed order (evolving blue, deepseek orange, glm aqua, opus yellow); lighter shades are the same hue at 40 % over the surface.
21. **Timing definitions:** `ttft_s` = first `message_start` − subprocess start (includes CLI start-up); per turn `gap_s` = last input event → `message_start` (first-token wait) and `gen_s` = `message_start` → `message_stop`; `model_s` = Σ(gap_s + gen_s); `tool_s` = Σ(tool_use block emitted → its tool_result). Whatever remains of `wall_s` is Claude Code overhead (tool execution not bracketed by a tool_use/tool_result pair, start-up, shutdown).

33. **Text-only models get a Read-on-image guard.** DeepSeek-V4-Pro and GLM-5.2 on Ark answer `400 Model do not support image input` when Claude Code attaches an image read with the Read tool, and because the image stays in the conversation every later request fails, so the run dies within a minute (observed 2026-09-10, 4 attempts). For models flagged `vision: false` in `models.yaml`, `run_one.py` writes a `PreToolUse` hook into the run's private `CLAUDE_CONFIG_DIR/settings.json` (`scripts/hooks/block_image_read.py`) that blocks Read on image files and tells the model it cannot view images and may OCR from the shell (`tesseract` is installed at /usr/local/bin). `harness/CLAUDE.md` and the prompts are unchanged for every model; check 13 stays a visual test that a text-only model can only pass via OCR, as TASK.md intends. `image_reads_blocked` is recorded in telemetry.

Reaching `--max-turns 60` makes Claude Code exit 1 with `error_max_turns`, which is a legitimate end of a run and is kept. The first version retried on any non-zero exit and re-ran both Evolving runs on 2026-09-11; both attempts are kept (`1_failed_attempt1` = first attempt).
37. **Sheet fallback for the vague prompt (check 11 / 12 / metric errors).** When a canonical sheet (`unit_economics`, `dcf`, `loan`) is absent, its metrics are searched by label across every sheet except the raw-data sheet, and `formula_ratio` is computed over those sheets instead of over an empty set (which scored 0 for any vague-prompt workbook with non-canonical sheet names, e.g. Evolving's `Monthly_Model` / `KPI_Summary`). c07 still fails when the sheets are missing. Sheets used are recorded in `check.json.stats.formula_ratio_sheets` / `sheet_fallback`.
